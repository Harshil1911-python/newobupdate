Deploy order (recommended)
--------------------------
1) WEB first (so live site used by online APK is fixed):
   - Upload web/orbit-native.js → https://orbitbillsphone.onrender.com/orbit-native.js
   - Upload web/billing.html → same host root
   - Confirm in browser: hard refresh, create invoice → PNG share still works

2) CAPACITOR APK:
   - In OrbitBillsForPhoneCapacitor repo:
       cp capacitor/package.json .
       cp capacitor/orbit-native.js www/
       cp capacitor/www/billing.html www/   # optional offline parity
   - npm install
   - npx cap sync android
   - Build APK (Actions or gradlew assembleDebug)
   - Install on phone; grant notifications when asked
